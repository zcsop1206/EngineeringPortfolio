# Study

Study docs for the notebook plugin's study mode. Written by a model for Adit, except where a doc says `by: adit`. Read them in Obsidian as they are: proofs and solutions are folded, so tap one open only after you have tried it. With study mode (Notebook 0.15) they open as linked docs with fog, drills, calls, marks and the Pencil on the page.

- **basics/**: the fundamentals. Each result is proved in exactly one basic; everything else links to it.
- **topics/**: thin docs: what to recognise, the first moves, the traps, and problems to try.
- **katas/**: design katas with test vectors; your design goes in the study view's editor.
- **bank/**: competition problems by source and number only, with links to the papers.
- **cards/**: numbers cards for the public projects, for interviews: every number is from the project's page.
- **tracks.md**: deadlines and weights the schedule works toward. Edit it.
- **registry.md**: every doc, planned or written, and its wave.
- **methods.md**: the method names a settle asks you to tick.
- **log/** and **ink/**: written by the plugin only.

The format is `docs/study/FORMAT.md` in the obsidian-notebook repo. This folder is in the public portfolio repo but is not published on the site; company-specific preparation lives outside it, in the private `interview-prep/` folder.
