> [!kata] I2C start, stop and one bit on an open-drain bus
> The bit layer of an I2C controller ([the bus](../basics/dd-serial.md#^i2c-bus), [its conditions](../basics/dd-serial.md#^i2c-conditions)). It never drives a line high: `scl_oe` = 1 pulls SCL low and `scl_oe` = 0 releases it, and the same for `sda_oe` and SDA. `scl_in` and `sda_in` are the bus levels as seen at each edge; a released line can still read 0 when another device holds it low. Outputs are checked right after every rising edge of `clk`.
>
> **Commands.** A rising edge with `cmd_valid` high, while `busy` is 0 and `rst` is low, accepts `cmd` and `din`: 0 START, 1 STOP, 2 WRITE the bit `din`, 3 READ a bit. A `cmd_valid` at an edge where `busy` was 1 before the edge is ignored; only `cmd` and `din` at the accepting edge matter.
>
> **Phases.** A command runs through phases 0, 1, 2, 3. Phase 0 starts right after the accepting edge. Each phase lasts two counted edges: the second counted edge after a phase starts begins the next phase. In phase 1 an edge counts only if `scl_in` is 1 at that edge; in the other phases every edge counts. Right after the edge that ends phase 3, `busy` = 0 and `done` = 1 for that one cycle; `busy` = 1 from the accepting edge until then.
>
> **Line levels** (`scl_oe`, `sda_oe`) during each phase, kept after the command ends until the next command changes them:
>
> | command | phase 0 | phase 1 | phase 2 | phase 3 |
> |---|---|---|---|---|
> | START | (unchanged, 0) | (0, 0) | (0, 1) | (1, 1) |
> | STOP | (1, 1) | (0, 1) | (0, 0) | (0, 0) |
> | WRITE `din` | (1, ~`din`) | (0, ~`din`) | (0, ~`din`) | (1, ~`din`) |
> | READ | (1, 0) | (0, 0) | (0, 0) | (1, 0) |
>
> "unchanged" means `scl_oe` keeps the value it had before the command.
>
> **Read.** For a READ, `dout` is `sda_in` at the edge that ends phase 2. `dout` holds at every other edge.
>
> **Reset.** `rst` (synchronous, active high) aborts any command and sets `scl_oe` = 0, `sda_oe` = 0, `busy` = 0, `done` = 0, `dout` = 0. It wins over `cmd_valid`.
>
> Example: from reset with no stretching, a START accepted at edge 0 shows (0, 0) after edges 0 to 3, (0, 1) after edges 4 and 5, (1, 1) after edges 6 and 7, and `done` = 1 right after edge 8; a command held on `cmd_valid` is accepted at edge 9.
